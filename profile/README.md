## First Questions

**Does NetSetMan Pro replace the network card driver?**  
No. NetSetMan Pro sits beside the adapter and the addresses you already keep for each desk.

**Can two travelers share one computer?**  
Yes. Each person keeps a separate NetSetMan Pro profile for their own location presets.

**Will NetSetMan Pro stay workable on an older office laptop?**  
Yes. NetSetMan Pro is meant to stay light during a normal switch on that PC.

**What should a new user try first?**  
One small NetSetMan Pro network profile today for a desk you use, then the same connection set again tomorrow.

## Field Note

NetSetMan Pro is easier to trust when the connection set stays smaller than the address pile it came from. A named session shows which desk is active, the pins show which network profile you will switch today, and the closing note tells the next person which location preset drives the adapter switch. That record is short on purpose: not a copy of every address, only the path back to the IP and DNS that are still open for the next desk.

The same loop fits a campus lab, a client office, or a computer carried between two rooms. Open the last NetSetMan Pro session, confirm one network profile, and leave the connection set easier to follow than you found it. Other programs stay where they are. NetSetMan Pro only holds the network profiles, the location presets, and the handoff.

## One Real Pass

Pick a desk that already has a name: the office, the home line, or a lab you visit. Open it in NetSetMan Pro, keep only that location preset on the board, and read one connection set you can point to. A pass is done when that IP and DNS stay tied to the network profile and the unused addresses are no longer in the way. NetSetMan Pro does not need a full rebuild of every adapter before it is useful.

If the pass feels crowded, the set is too wide. Drop anything that belongs to a different desk and leave it out of this workspace. The next pass can have its own title. What matters is that this one stays readable from the first network profile to the last adapter switch, with the summary still matching the connection set on that desk.
